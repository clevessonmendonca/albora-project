## 📝 NOTAS DE IMPLEMENTAÇÃO

### Decisões de Design
1. **Skip Link** — focável no topo, vai para `#main-content`
2. **LiveAnnouncer** — sistema global de announcements, polite
3. **GuestMain como `<main>`** — landmark semântico obrigatório
4. **role="feed"** — identifica área de feed social
5. **aria-current="page"** — filtros ativos (mais adequado que apenas aria-pressed)
6. **Focus trap leve** — MenuOpcoes foca primeiro item mas permite Tab out
7. **Star animation** — respeitada por prefers-reduced-motion

### Padrões ARIA Utilizados
- `role="dialog"` + `aria-modal="true"` — modais
- `role="feed"` — feed social
- `aria-live="polite"` — announcements não urgentes
- `aria-busy="true"` — loading states
- `aria-current="page"` — item ativo em navegação
- `aria-pressed` — estado toggle
- `aria-expanded` — estado expandido
- `aria-label` / `aria-labelledby` — labels customizados
- `aria-describedby` — descrição adicional
- `aria-hidden="true"` — elementos decorativos
- `role="status"` — status messages

### Classes Utilitárias
- `.sr-only` — visível apenas para screen readers
- `focus-visible:` — indicadores de foco para teclado
- `motion-reduce:` — fallbacks para prefers-reduced-motion
