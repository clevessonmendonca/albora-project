## O que o sistema agora oferece (use; não reinvente)
- **Espaço** (múltiplos de 4; use SEMPRE `var(--space-N)`): 1=4 · 2=8 · 3=12 · 4=16 · 5=20 · 6=24 · 8=32 · 10=40 · 12=48 · 16=64. Regra de proximidade: 1–3 dentro do componente · 4–6 entre irmãos do mesmo grupo · 8–10 entre grupos · 12–16 entre seções. Título → descrição = `space-2`; descrição → conteúdo = `space-5/6`; campo → campo = `space-5`; último campo → botão = `space-6`; cabeçalho de página → corpo = `space-8`. Margem lateral da página = `var(--gutter)`; respiro entre seções = `var(--section)`. Utilitários prontos: `.stack` (+`stack-2/3/5/6`), `.flex`, `.grid`.
- **Tipografia** (tokens `--fs-*`; **só estes**): `xs 12` (rótulo versalete, nunca abaixo de 12) · `sm 14` (metadado/legenda) · `md 16` (corpo e campos) · `lg 18` (lead) · `xl 22` · `--fs-title` e `--fs-display` fluidos (clamp) · `--fs-hero` (numeral herói). Classes `t-display/t-title/t-h/t-lead/t-small/t-label/t-num`. Corpo ≥16px; leitura ≤ `--measure` (62ch); Fraunces só em título, numeral herói, nome próprio e momentos editoriais; Instrument Sans em tudo que é interface. Peso: 400 corpo, 500 rótulo/botão, 600 só `t-h`. Sem negrito em frases inteiras.
- **Contêineres**: `--w-narrow 720`, `--w-page 1040`, `--w-wide 1240`, `--w-feed 560`. Nada se estica além disso em monitor grande.
- **Movimento**: 120 ms (toque/hover/pressed) · 200 ms (mudança de estado) · 320 ms (entrada/saída de overlay, troca de etapa); curva `var(--ease)`; só `transform` e `opacity`; sempre com `@media (prefers-reduced-motion:reduce)` (já global). Momentos expressivos (estrela/mascote/`A.celebrate`) só em: 1ª foto enviada, evento criado (Pronto), telão conectado.
- **Contraste/tema (por construção)**: `--fg`, `--fg-2`, `--fg-3`, `--accent-text`, `--on-ac`, `--control` já são tokens validados (texto ≥4.5:1, controles ≥3:1). **Nunca escreva uma cor de texto/borda de controle fora desses tokens.** Cor de evento/fornecedor passa pelo motor `A.theme.resolve(hex, 'noite'|'papel')` / `A.theme.scope(hex,'papel')`; botão sobre acento usa `var(--on-ac)`, nunca `--papel`/`--noite` fixos. Opacidade em texto é proibida (opacity reduz contraste): use `--fg-2/--fg-3`.
- **Ícones**: Lucide real (`A.icon(nome, 16|20|24, cls, {fill:true})`, traço 1.75). Ícone de ação sempre com `aria-label`/texto; ícone + texto = `gap: var(--space-2)`; área de toque ≥44×44 (use `.btn-icon`; `.btn-sm`/`.chip` já têm área de 44 por pseudo-elemento).
- **Estados de botão**: default · hover · `:focus-visible` · pressed (scale .977) · disabled · `.is-loading` · sucesso/erro via toast + texto do botão ("Enviar" → "Enviada"). Idem campos (foco, erro, desabilitado, preenchido).
- **Mobile-first**: escreva o CSS do menor para o maior (`min-width`), parta de 320px. Alvos ≥44px; `env(safe-area-inset-*)` em barras fixas; conteúdo nunca atrás da barra inferior (`padding-bottom` já no `.page`; no convidado, a `.gnav`); teclado virtual não pode esconder campo/botão (use `scroll-margin`, campos de ação em sheet com `position:sticky` na base); tabelas viram lista/linha em <760px (ou rolam dentro de `.table-wrap` com sentido explícito); sem larguras fixas em px para contêiner (use `minmax()`, `clamp()`, `%`/`ch`); paisagem em celular (altura <500px) não pode esconder CTA.
- **Alinhamento/centralização**: centralize só o que é cerimonial (capa, vazios, confirmação). O resto alinha à esquerda numa coluna única. Centralização *óptica* de ícone+texto: `inline-flex; align-items:center`. Nada de margem negativa ou `transform` para consertar posição — conserte a estrutura.

## Direção emocional (resumo)
Elegante, aconchegante, íntimo — nunca corporativo frio, neon, coração decorativo, floral genérico, rosa-clichê, infantil, luxo exagerado. Âmbar = assinatura calorosa (filete, ponto, foco, recompensa), nunca superfície grande. Foto e pessoas são o protagonista; a interface recua. Tom de texto: curto, caloroso, claro para qualquer idade; sem jargão. Movimento delicado: reação com resposta sutil, foto que abre suavemente, envio que acolhe; nunca festa de confete.
